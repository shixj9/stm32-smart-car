# STM32 Smart Car（基于 STM32F103C8T6 的多功能智能小车）

基于 **STM32F103C8T6** 最小系统核心板（HAL 库 + STM32CubeMX + Keil MDK-ARM V5）开发的四轮驱动多功能智能小车项目。原型阶段通过面包板完成硬件搭建与联调，实现了**蓝牙遥控**、**SG90 云台超声波探路 + MPU6050 陀螺仪闭环避障**、**亚博智能八路灰度 PD 循迹**以及 **0.96 寸 OLED 实时状态面板**；同时在 `hardware/` 目录下保留了后续计划自制 PCB 的嘉立创 EDA 专业版设计初稿。

## 二、硬件组成与引脚连接说明

系统主频配置为 **72 MHz**（外部 8 MHz 晶振 HSE × PLL 9 倍频），启用 SWD 调试接口（`PA13` / `PA14`）并通过 `__HAL_AFIO_REMAP_SWJ_NOJTAG()` 关闭 JTAG 以释放 `PB3`、`PB4` 作为普通 GPIO 使用。

### 1. 外设引脚分配表

| 功能模块 | 模块信号 | MCU 引脚 | 外设 / 工作模式 | 连接与配置说明 |
| :--- | :--- | :--- | :--- | :--- |
| **前轮驱动 (TB6612 #1)** | `PWMA`（前左调速） | `PA0` | `TIM2_CH1` (PWM) | 1 kHz PWM (`PSC=71, ARR=999`) |
| | `PWMB`（前右调速） | `PA1` | `TIM2_CH2` (PWM) | 1 kHz PWM (`PSC=71, ARR=999`) |
| | `AIN1` / `AIN2` | `PA2` / `PA3` | `GPIO_Output` | 前左轮正反转控制（前进：`PA2=1, PA3=0`） |
| | `BIN1` / `BIN2` | `PA4` / `PA5` | `GPIO_Output` | 前右轮正反转控制（前进：`PA4=1, PA5=0`） |
| | `STBY` | `PA6` | `GPIO_Output` | 前驱动芯片使能（高电平有效） |
| **后轮驱动 (TB6612 #2)** | `PWMA`（后左调速） | `PB10` | `TIM2_CH3` (PWM) | `TIM2` 部分重映射 (`PARTIAL_2`)，1 kHz PWM |
| | `PWMB`（后右调速） | `PB11` | `TIM2_CH4` (PWM) | `TIM2` 部分重映射 (`PARTIAL_2`)，1 kHz PWM |
| | `AIN1` / `AIN2` | `PB12` / `PB13` | `GPIO_Output` | 后左轮正反转控制（前进：`PB12=0, PB13=1`） |
| | `BIN1` / `BIN2` | `PB14` / `PB15` | `GPIO_Output` | 后右轮正反转控制（前进：`PB14=0, PB15=1`） |
| | `STBY` | `PB1` | `GPIO_Output` | 后驱动芯片使能（高电平有效） |
| **云台舵机 (SG90)** | `PWM` 信号线 | `PA7` | `TIM3_CH2` (PWM) | 50 Hz (`PSC=719, ARR=1999`)；`50`=右, `150`=中, `250`=左 |
| **超声波 (HC-SR04)** | `Trig` 触发输入 | `PB0` | `GPIO_Output` | 输出约 15 μs 高电平脉冲触发测距 |
| | `Echo` 回响输出 | `PA8` | `TIM1_CH1` (IC) | 输入捕获中断 (`PSC=71`, 1 μs 计数)，`PA8` 为 5V 耐受引脚 |
| **OLED & MPU6050** | `SCL` 时钟线 | `PB8` | `GPIO_Output_OD` | 软件模拟 I2C 共用总线（OLED 地址 `0x78`，MPU 地址 `0xD0`） |
| | `SDA` 数据线 | `PB9` | `GPIO_Output_OD` | 开漏输出 + 内部上拉，MPU6050 的 `AD0` 接地 |
| **八路灰度循迹（亚博智能）** | `AD0` / `AD1` / `AD2` | `PB3` / `PB4` / `PB5` | `GPIO_Output` | 3-8 通道选择地址线，轮询选通第 `0 ~ 7` 路传感器 |
| | `OUT` 数字输出 | `PB6` | `GPIO_Input` | 读取当前选通通道灰度状态（上拉输入，`1` 代表黑线） |
| **蓝牙串口 (JDY-31)** | 蓝牙 `RXD` | `PA9` | `USART1_TX` | **交叉连接**：MCU 发送端 `PA9` 接蓝牙模块 `RXD`（9600 bps） |
| | 蓝牙 `TXD` | `PA10` | `USART1_RX` | **交叉连接**：MCU 接收端 `PA10` 接蓝牙模块 `TXD`（中断接收） |
| **调试接口** | `SWDIO` / `SWCLK` | `PA13` / `PA14` | `SYS_SWD` | ST-Link SWD 烧录与在线调试 |

## 三、软件功能与控制协议

主程序以 **10 ms** 为核心调度节拍：每轮循环更新 MPU6050 偏航角积分与当前模式控制逻辑，每 **100 ms** 非阻塞刷新一次超声波距离，每 **200 ms** 刷新一次 OLED 屏幕。

### 1. 蓝牙串口指令集（波特率 `9600, 8-N-1`）

通过手机蓝牙串口助手向 JDY-31 发送单字符即可随时切换工作模式或遥控移动：

| 发送字符 | 功能说明 | 备注 |
| :---: | :--- | :--- |
| `'0'` | **待机模式 (`Standby`)** | **最高优先级急停**：任意时刻（含避障扫描/转向途中）发送 `'0'` 均立即停车、云台回正 |
| `'1'` | **蓝牙遥控模式 (`Remote`)** | 进入手动遥控状态，切换瞬间自动清空残留方向指令 |
| `'2'` | **自主避障模式 (`Obstacle`)** | 前方 `2 ~ 25 cm` 遇障时急停，舵机云台左右探路后通过 MPU6050 闭环原地转向 90° |
| `'3'` | **自主循迹模式 (`Tracking`)** | 八路灰度加权 PD 差速循迹，具备左右直角弯锁定过弯与脱离黑线自动停车保护 |
| `'F'` / `'B'` | 前进 / 后退 | 仅在模式 `'1'`（蓝牙遥控模式）下有效，基础占空比 `500 / 999` |
| `'L'` / `'R'` | 原地左转 / 原地右转 | 仅在模式 `'1'`（蓝牙遥控模式）下有效，转向占空比 `200 / 999` |
| `'S'` | 停止 | 仅在模式 `'1'`（蓝牙遥控模式）下有效 |

### 2. OLED 状态屏显示说明

```text
+----------------------+
| A:1 M:3   X12  00    |  <- 第1行：循迹动作码 A (0~4)、当前模式 M (0~3)、灰度 X1~X2
| Tracking  X34  11    |  <- 第2行：当前模式英文名称、灰度 X3~X4
| Y:  0.0   X56  00    |  <- 第3行：MPU6050 偏航角 Yaw (°)，未接显示 MPU_ERR、灰度 X5~X6
| D: 32.5cm X78  00    |  <- 第4行：超声波距离 D (cm)，超量程显示 D:ERR、灰度 X7~X8
+----------------------+
```

* **`A:x` 循迹状态码**：`0` = 待机/初始，`1` = PD 闭环循迹，`2` = 左直角弯锁定，`3` = 右直角弯锁定，`4` = 全灭出线停车保护。

## 四、编译与烧录说明

1. **开发环境**：
   * IDE：**Keil MDK-ARM V5**（工程文件：`ITcar/MDK-ARM/ITcar.uvprojx`，已配置 `--no-multibyte-chars` 原生兼容 UTF-8 中文注释）
   * 代码生成工具：**STM32CubeMX 6.9.1**（固件包 `STM32Cube FW_F1 V1.8.7`）
2. **编译与下载**：
   * 使用 Keil 打开 `ITcar/MDK-ARM/ITcar.uvprojx`，点击 `Build (F7)` 编译生成可执行文件。
   * 通过 ST-Link 连接最小系统板的 `SWDIO (PA13)`、`SWCLK (PA14)`、`GND`、`3V3` 下载程序。
3. **上电校准提示**：
   * 上电后前 **2 秒**内程序会自动对 MPU6050 进行 200 次静态零偏采样校准，**上电瞬间请保持车身静止平放**，待 OLED 点亮显示数据后再开始操作。

## 五、硬件 PCB 初稿说明（`hardware/`）

早期功能验证基于面包板与杜邦线搭接完成，`hardware/` 目录保存了后续尝试自绘电路板时的 **3 份嘉立创 EDA 专业版（LCEDA Pro）工程归档（`.eprj2`）**：

1. **`开发板ITcar.eprj2`**：最初的原理图草稿，仅包含原理图页，尚未建立 PCB。
2. **`STM32F103C8T6.eprj2`**：一体式主控底板方案初稿（将 STM32F103C8T6 最小系统与外设接口集成在同一块 PCB 上），含原理图与 PCB 初稿。
3. **`stm32小车拓展板.eprj2`**：拓展底板（Shield）方案初稿（直接插接现成 STM32F103C8T6 核心板并引出各传感器与电机驱动插座），含原理图与 PCB 初稿。

> **注意**：`hardware/` 下的板卡设计均为**未投板打样验证的初稿**，仅供参考或在此基础上继续完善。打开方式：使用 **嘉立创 EDA 专业版** -> `文件` -> `导入` -> `嘉立创EDA专业版 (.eprj2)`。
>
> **后续继续完善 PCB 时的硬件核对建议**：
> * **蓝牙串口线序**：务必确保 `PA9 (USART1_TX)` 接蓝牙模块的 `RXD`，`PA10 (USART1_RX)` 接蓝牙模块的 `TXD`。
> * **5V 电平防护**：HC-SR04 超声波模块需 5V 供电，其 `Echo` 引脚输出 5V 电平；`PA8` 虽为 5V 耐受引脚，画板时建议串联 `1 kΩ` 限流电阻或做 `1 kΩ + 2 kΩ` 分压。
> * **前后电机插座线序**：当前固件中前轮正转为 `IN1=1, IN2=0`，后轮正转为 `IN1=0, IN2=1`（面包板物理接线镜像所致），布板统一电机座极性时可同步调整线序或宏定义。
